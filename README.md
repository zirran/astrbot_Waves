# 海浪 · astrbot_plugin_wave

- **必须配 embedding 模型**，否则没有语义边与向量近邻，只剩标签联想

- 希望这个插件成为一个公众项目，让百家争鸣成为集百家之长，打造真正的既省Token又可以帮助ai去更好的，更长久的去记住“你”与ta的一切。

给 AstrBot 的**记忆 + 日记 + 情感 + 星图**一体化插件。

四层记忆、150 词标签体系、情感加权、标签联想与两跳推理、真实遗忘、带大纲的日记与年度合集、以及一个可交互的 3D 记忆星图。

> 适用于 AstrBot `>= 4.17.0`，OneBot v11（SnowLuma / NapCat）私聊场景。

## 一、它解决什么问题

普通聊天机器人「记不住」：上下文一过就忘，或者把几百条历史一股脑塞进 prompt 烧 token。

海浪把记忆拆成四层，各管各的寿命；更重要的是——**记忆不依赖上下文存活**，它存在磁盘上，需要时被检索回来，重要的直接写进人格。

---

## 二、四层记忆

| 层 | 内容 | 寿命 | 是否进人格 |
|---|---|---|---|
| **L1** | 最近十句原话（摘要 + 5 标签） | 滚动窗口 | 走上下文 |
| **L2** | 24 小时内的闲聊摘要 | 到期即删（热门可续期） | 按话题注入 |
| **L3** | 偏好、约定、身份、习惯 | 永久（除非被遗忘） | ✅ 写进人格 |
| **L4** | 每日原话存档 + 日记 | 永久 | 检索 / 翻档案时使用 |

### L3 入库质量门槛

不是什么都进长期记忆：

```
有长期信号词（喜欢/讨厌/习惯/约定/以后/每次/不要/名字/生日/边界…）→ 收
只有瞬时词（今天/刚才/现在/好累…）且无长期信号 → 拒
长度 < 8 或 > 160 → 拒
```

**例外**：你明确说「记住」而写入的事实（`pinned`）绕过所有门槛，且永不下沉。

---

## 三、标签体系

- 词表 **150** 个标签，按人物 / 工作 / 技术 / 游戏 / 影音 / 饮食 / 作息 / 消费 / 家居 / 情绪 / 关系 / 元信息分组
- 每条记忆**固定 5 个标签**
- 词表覆盖不到时允许**自造 1–2 个 2–4 字短标签**（存最多 7 个）
- 新标签会与已有标签做**近似归一**（编辑距离 ≤1 自动合并，避免「螺蛳粉/螺丝粉」分裂）

L4 每日存档也会按当天 L2 的标签聚合出 top4，所以档案层同样参与联想。

## 四、联想与检索

### 候选来源（四条并行）

```
1. 标签命中      查询里出现词表标签
1.5 标签共现     命中标签的兄弟标签（共享 ≥2 条记忆）
1.6 语义标签     把 150 个标签也向量化，按余弦找最近的标签
1.7 向量近邻     直接用查询向量在全库找最近邻（默认阈值 0.55）
2.  字面兜底     只在完全没候选时启用
```

### 打分

```
score = Σ(1 + log(1 + 60/df)) × 1.4     标签 IDF（稀有标签权重更高）
      + cos(query, mem) × 2.0            语义相似
      + jaccard(query, mem) × 1.2        字面相似
      + min(0.6, hits × 0.06)            被想起次数
      + max(0, 0.35 - 天数×0.01)         新鲜度
      + 0.9 × (1 - |情绪差|)             情绪共鸣
      + 0.35 / 0.25                      长期事实 / 日记加成
```

### 过滤（拒绝无用联想）

```
证据门槛：必须有「标签命中」或「余弦 ≥0.55」或「字面相似 ≥0.25」
去重门槛：与已选记忆相似度 ≥0.72 的丢弃
分数门槛：低于 1.2 的不注入（自适应，范围 0.8–1.5）
噪音过滤：寒暄类摘要（"简单应声""表示知道了"）不注入
```

### 两跳扩展

从最强的 3 条往外走，每跳取**关联更强 + 优先跨层**的邻居；链上会标注搭桥的标签：

```
主人是大学生 → 主人希望称呼他为"主人" ⟨称呼⟩ → 每次多写几句 ⟨边界⟩
```

桥标签必满足：出现频率 ≤20%（不是"主人"这种泛标签），且不属于元标签（日程/记忆/日记/提醒/计划/目标/任务/项目/L4）。

## 五、情感理解

- 每条记忆存 `{label, v}`，`v ∈ [-1, 1]`
- 查询情绪由 **40 词词典 + 否定词翻转**判定（"不开心" → 负，"别担心" → 正）
- 检索时情绪相近的记忆加分
- 注入时给**情绪底色**（近 7 天平均，|avg| ≥ 0.15 才提示）
- 命中记忆带强情绪时给**情绪共鸣**提示
- 情绪极值触发硬规则：

```
qval ≤ -0.5 → 【他现在的状态】情绪很沉。先接住，别给建议、别分析原因
qval ≥ +0.5 → 【他现在的状态】心情不错，顺着聊，别扫兴
```

## 六、真实遗忘

```
稳定性 = 1 + 2 × 被想起次数
强度   = e^(-天数/稳定性) + 0.06 × min(5, hits)
```

| 触发 | 结果 |
|---|---|
| L2 强度 < 0.08 或超 24h | 删除，写入 `forget_log.jsonl` |
| L2 被提起 ≥2 次 | 到期前续 48h，最长 3 天 |
| L2 被提起 ≥3 次且信息量够 | **晋升 L3**（热点自动转长期） |
| L3 强度 < 0.12 且只提起 1 次 / 180 天没提 | 标记 `parked`，退出人格 |
| L3 下沉满 365 天 | 彻底删除 |
| L4 | 永不删除 |

再次提到旧事、或被检索命中，都会 `hits + 1` —— 用进废退。

## 七、日记与年度合集

- 默认每 **14 天**写一篇
- 格式：`日期 · 标题` → `【大纲】3–5 条` → `【正文】250–450 字`
- 人格里保留最新 1 篇（含正文），更早的只留大纲
- **满 24 篇自动合成 1 篇年度合集**（带独立大纲），原 24 篇删除
- 启动时若已超阈值会自动补一次合并

```
/日记 现在   立刻写一篇（管理员）
/日记 合并   手动触发合集合并（管理员）
```

## 八、记忆星图

插件启动后在 `web_port`（默认 **8788**）起一个只读页面：

```
http://<服务器IP>:8788/
```

- 3D 斐波那契球分布，可拖动旋转、滚轮/按钮缩放
- 放大到 1.55× 显示内容，2.1× 显示标签，2.6× 显示长文本
- 左上角按 **1 小时 / 6 小时 / 24 小时 / 全部** 过滤
- 底部「生命树」：枝条是一次联想，叶子是被想起的记忆，点叶子回放
- 右侧详情：层级、时间、剩余有效期、记忆强度、情绪、联想列表
- 纯静态页面 + `/api/cloud` 接口，无外部依赖

## 九、自我迭代

| 机制 | 频率 | 作用 |
|---|---|---|
| 事实去重 | 每次清理 | 相似度 ≥0.72 的事实合并（标签并集、hits 相加） |
| 热点晋升 | 每次清理 | L2 被提起 ≥3 次 → 转 L3 |
| 定期自审 | 每 7 天 | 让模型合并重复、改写含糊描述（提示词要求保守） |
| 全局门槛自适应 | 每 20 次检索 | 命中率低 → 降门槛；总是命中 → 升门槛 |
| 话题门槛自适应 | 每 8 次检索（按话题） | 每个话题独立的向量相似度阈值（0.45–0.70） |
| 日记合并 | 超 24 篇 | 合成年度合集 |

## 十、指令与工具

### 指令

| 指令 | 作用 |
|---|---|
| `/记忆` | 四层状态 |
| `/记忆 事实` | 看长期记住了什么 |
| `/记忆 整理` | 合并去重（管理员） |
| `/记忆 搜 关键词` | 翻永久存档 |
| `/记忆 联想 话题` | 看两跳联想链 |
| `/日记` | 最近一篇（大纲 + 正文） |
| `/日记 大纲` | 只看大纲 |
| `/日记 现在` | 立刻写一篇（管理员） |
| `/日记 合并` | 手动合并合集（管理员） |
| `/海浪` | 全层状态 + 图规模 + 标签数 |

### 给模型的工具

| 工具 | 用途 |
|---|---|
| `memory_search(query)` | 按话题检索记忆（标签 + 向量 + 跨层扩展） |
| `memory_save(text, tags)` | 主动写入一条长期记忆 |
| `recall_archive(keyword)` | 在永久存档里搜原话 |

### 「记住」即时通道

消息里出现 `记住 / 记得 / 别忘 / 记牢 / 记一下 / 要记 / 记着 / 帮我记` 时：

```
1. 提取事实（一次 LLM 调用 → JSON：fact / tags / emotion）
2. 直接写 L3（pinned=True），绕过压缩
3. 立刻刷新人格
```

## 十一、安装与配置

```bash
cd AstrBot/data/plugins
git clone https://github.com/zirran/astrbot_Waves.git
```

重启后填这三项即可工作：

```json
"owner_id": "你的QQ号",
"persona_id": "要写入的人格名",
"cheap_provider_id": "deepseek/deepseek-flash"
```

建议同时配向量模型（不配就没有语义联想，只剩标签联想）：

```json
"embedding_provider_id": "bailian_embedding"
```

### 主要配置项

| 键 | 默认 | 说明 |
|---|---|---|
| `owner_id` | 16774996 | 只对这个人的私聊做记忆 |
| `persona_id` | 大肥鱼 | 长期记忆与日记写进哪个人格 |
| `recall_top_k` | 5 | 检索命中数量 |
| `recall_inject_max` | 5 | 注入条数上限（高分时自动降到 3） |
| `recall_score_floor` | 1.2 | 注入分数门槛（会自适应） |
| `assoc_expand` | 2 | 一跳扩展条数 |
| `embed_min_sim` | 0.74 | 语义边阈值 |
| `graph_max_degree` | 8 | 每点最多连几条 |
| `forget_l3_below` | 0.12 | L3 下沉强度阈值 |
| `diary_interval_days` | 14 | 日记周期 |
| `diary_digest_every` | 24 | 多少篇合成合集 |
| `self_review_days` | 7 | 自审周期 |
| `web_port` | 8788 | 星图端口 |

## 十二、省 Token 设计

| 机制 | 效果 |
|---|---|
| 短消息跳过检索 | "嗯/好/在吗" 不调 embedding、不注入 |
| 寒暄批次跳过模型 | 全是短句的批次本地打标签，不调用 LLM |
| 提示词只放 64 核心标签 | 每次调用省约 250 token |
| 注入条数自适应 | 高分时只给 3 条 |
| 每条记忆截断 50 字 | 少说废话 |
| 图重建后台化 | 不阻塞回复，15 秒节流 |
| 大对象缓存 | 文本相似度、会话解析、情绪趋势、边权重 |
| 句尾句号过滤 | 发送前强制剥离，不靠模型自觉 |

## 十四、注意事项

1. **必须配 embedding 模型**，否则没有语义边与向量近邻，只剩标签联想
2. 阿里 embedding 接口单批上限 10，`embed_batch` 不要超过 10
3. 星图端口需要放行或用 SSH 隧道访问
4. 人格会被改写（`【长期记忆】` / `【云上日记】` 两段），**请先备份原人格**
5. 门槛自适应需要积累样本（全局 20 次、话题 8 次）才开始调节
6. 日记合并不可逆（原篇会删），重要日记建议另存
