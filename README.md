## 它解决什么问题

普通机器人「记不住」：上下文一过就忘，或者把几百条历史一股脑塞进 prompt 烧 token。

海浪把记忆拆成四层，各管各的寿命。更重要的是：

> **记忆不依赖上下文存活。** 它存在磁盘上，需要时检索回来，重要的直接写进人格。

对话被截断、上下文被清、甚至换模型，核心记忆都还在。

## 快速开始

```bash
cd AstrBot/data/plugins
git clone https://github.com/zirran/astrbot_Waves.git
```

重启 AstrBot，填四项即可：

```json
{
  "owner_id": "你的QQ号",
  "persona_id": "要写入的人格名",
  "cheap_provider_id": "deepseek/deepseek-flash",
  "embedding_provider_id": "bailian_embedding"
}
```

星图地址在启动日志里（带 token），默认端口 `8788`。

## 四层记忆

| 层 | 内容 | 寿命 | 进人格 |
| --- | --- | --- | --- |
| **L1** | 最近 20 句原话（摘要 + 标签） | 滚动窗口 | 走上下文 |
| **L2** | 24 小时内的闲聊摘要 | 到期即删，热门续期 | 按话题注入 |
| **L3** | 偏好、约定、身份、习惯、边界 | 永久（除非被遗忘） | ✅ |
| **L4** | 每日原话存档 + 日记 | 永久 | 检索 / 翻档案 |

**L3 入库门槛**：有长期信号词（喜欢 / 讨厌 / 习惯 / 约定 / 以后 / 每次 / 不要 / 名字 / 生日 / 边界）才收；
只有瞬时词（今天 / 刚才 / 好累）且无长期信号就拒；长度 < 8 或 > 160 拒。
你说「记住」而写入的事实绕过所有门槛，且永不下沉。

## 情绪系统

### 一、识别你的情绪

| 能力 | 例子 |
| --- | --- |
| 分句作用域 | `不是很难过，就是有点累` 两句分别判 |
| 否定与否定尾 | `不开心` / `开心不起来` / `喜欢不了` |
| 双重否定 | `不是不开心` → 正面 |
| 程度词 | `超级 / 特别 / 太 / 有点 / 稍微`，前后都吃 |
| 转折取后句 | `虽然烦，但是见到你就好了` → 后句为主 |
| 假设降权 | `要是 / 如果 / 的话` → ×0.75 |
| 反问降置信 | `难道…吗？` → ×0.6 |
| 转述降权 | `他说 / 她在 / 他们` → ×0.45，不算她的情绪 |
| 持续标记 | `最近 / 一直 / 老是` → 标为持续情绪 |
| emoji / 表情码 | 😭😄 计入，`[em]e10317[/em]` 剥掉 |
| 中性词 | `还行 / 就那样` → 不触发安慰 |
| 强度分级 | 强情绪单独触发安抚 |
| 弱信号平滑 | `|v| < 0.45` 与上一句 0.65/0.35 混合，单字不跳变 |

### 二、她自己的情绪

```
v_new   = 惯性 × v_old + (1-惯性) × 基线 + 耦合 × 你的情绪 + 事件
arousal = 0.75 × 旧唤醒 + 0.25 × 你的强度 + 事件唤醒
```

| 成分 | 默认 | 说明 |
| --- | --- | --- |
| 惯性 | 0.88 | 情绪不会一句就翻盘 |
| 基线 | 0.08 | 长期回到微微偏正 |
| 耦合 | 0.35 | 被你感染的程度 |
| 事件 | — | 被夸 +0.15、被凶 −0.25、被敷衍 −0.08、被依赖 +0.05、被逗笑 +0.08 |
| 创伤 | — | 被凶后恢复更慢几轮 |

**二维表达**：高唤醒+正「挺来劲」，低唤醒+正「挺松快」，
高唤醒+负「有点烦躁」，低唤醒+负「提不起劲」，中性+高唤醒「有点躁」。

**交叉规则**：你低落、她也低落时，允许她说实话，不硬装开心。

### 三、自我迭代

| 回复情绪 vs 设定情绪 | 调整 |
| --- | --- |
| 差距 > 0.55 | 耦合 −0.02、惯性 +0.01 |
| 差距 < 0.20 | 耦合 +0.01 |
| 长期偏移 | 基线每次 ±0.004 |

### 四、情绪历史

`/情绪` 和情绪页的数据来自 `mood_log.jsonl`，首次会用 **L4 存档** 回填：
把你说过的每句话判一遍情绪，按天聚合；她那一路按同一批数据重放。
实测能覆盖 8 天以上，之后实时数据继续追加。

## 联想与检索

### 候选（四路并行）

```
1.   标签命中    查询里出现词表标签
1.5  标签共现    命中标签的兄弟标签（共享 ≥2 条记忆）
1.6  语义标签    150 个标签向量化，按余弦找最近标签
1.7  向量近邻    查询向量在全库找最近邻（阈值 0.55，按话题自适应）
2.   字面兜底    完全没候选时才启用
```

### 打分

```
score = Σ(1 + log(1 + 60/df)) × 1.4     标签 IDF
      + cos(query, mem) × 2.0            语义
      + jaccard(query, mem) × 1.2        字面
      + min(0.6, hits × 0.06)            被想起次数
      + max(0, 0.35 - 天数×0.01)         新鲜度
      + 0.9 × (1 - |情绪差|)             情绪共鸣
      + 0.35 / 0.25                      长期事实 / 日记加成
```

### 过滤

```
证据门槛：标签命中 或 余弦 ≥0.55 或 字面 ≥0.25
去重门槛：与已选记忆 ≥0.72 丢弃
分数门槛：低于 score_floor 不注入（自适应 0.8–1.5）
字符预算：单次 ≤240 字（调优器 140–420）
噪音过滤：寒暄类摘要不注入
```

### 三段落召回

```
正常门槛 → 空
门槛 ×0.72 + 带上你上一句话 → 空
门槛 0.55，只用原句 → 空就放弃（不硬塞旧事）
```

### 两跳扩展

从最强的 3 条往外走，每跳取关联更强、优先跨层的邻居，链上标注搭桥标签：

```
主人是大学生 → 希望称呼他为主人 ⟨称呼⟩ → 每次多写几句 ⟨边界⟩
```

桥标签条件：出现频率 ≤20%，且不属于元标签。

## 真实遗忘

```
稳定性 = 1 + 2 × 被想起次数
强度   = e^(-天数/稳定性) + 0.06 × min(5, hits)
权重   = 类型基础分 + 0.5 × (被想起次数 - 1) - 0.1 × 天数
```

| 触发 | 结果 |
| --- | --- |
| L2 强度 < 0.08 或超 24h | 删除，写 `forget_log.jsonl` |
| L2 被提起 ≥2 次 | 到期前续 48h，最长 3 天 |
| L2 被提起 ≥3 次且信息量够 | 晋升 L3 |
| L3 权重 < 1.0 或 180 天没提 | 标 `parked`，写 `facts_archive.json` |
| 每天下沉上限 | 最多 3 条 |
| 下沉满 365 天 | 彻底删除 |
| L4 | 永不删除 |
| 活跃事实 > 容量 ×1.3 | 启动时自动裁到容量 |

类型基础分：约定 / 承诺 / 身份 / 边界 **3.0** · 偏好 / 作息 / 习惯 **2.5** · 梗 / 表情 **1.6** · 其他 **1.3**。

## 日记

- 默认每 **14 天**一篇
- 格式：`日期 · 标题` → `【大纲】3–5 条` → `【正文】250–450 字`
- 人格里保留最新一篇正文，更早的只留大纲
- 满 24 篇自动合成年度合集，原篇删除
- `/日记 现在` 立刻写，`/日记 合并` 手动合并

## 三个页面

启动后在 `web_port`（默认 **8788**）起三个带令牌保护的页面：

```
http://<服务器IP>:8788/?token=<state.json 里的 web_token>
```

### 星图

- **环形分类**：按层级分圈（L1 / L3 / L2 / L4 / 日记），圈内按标签排序
- **球面散布**：自由探索，`⌗` 切换
- 拖动旋转（带惯性）、滚轮缩放（缓动）、搜索过滤、导出 PNG
- 悬停气泡、选中脉冲、时间过滤、底部时间轴
- 自适应画质：帧率低时自动关辉光

### 情绪页

| 元素 | 含义 |
| --- | --- |
| 墨色柱 | 她每天的情绪均值（0 以上偏轻，以下偏沉） |
| 折线 | 你每天的情绪均值 |
| 底部细条 | 她今天逐小时 |
| 右栏 | 我此刻 / 你这边 / 耦合 / 惯性 / 自适应次数 |

直接打开：`/?open=mood`

### 记忆实验室

- 顶部：近 7 天请求、缓存命中、输入 token、估算费用（真实数据）
- 搜索内容或标签，切换 全部 / L3 / L2 / L4
- 每条显示标签、被想起次数、可信度、置顶 / 下沉 / 过期状态
- 一键 **置顶 / 取消置顶 / 下沉 / 作废 / 删除近期笔记**

接口：

```
GET  /api/mem?q=&layer=&limit=
POST /api/mem        {"id":"…","op":"pin|unpin|park|void|drop"}
GET  /api/usage?days=7
GET  /api/mood
```

本机或 SSH 隧道访问免令牌；外网访问仍需 `?token=`。

## 省钱

| 机制 | 效果 |
| --- | --- |
| 短消息跳过检索 | 「嗯 / 好 / 在吗」不调 embedding |
| 寒暄批次跳过模型 | 本地打标签 |
| 注入预算 | 240 字 / 4 条，调优器自适应 |
| 人格哈希 | 内容没变不重写人格，保护前缀缓存 |
| 检索缓存 | 同一句 15 分钟内复用 |
| 缓存自调优 | 读 `provider_stats`，每 10 轮爬山调参，退步回滚 |
| 群聊限流 | 超限直接不回，模型都不调 |

**实测**（provider_stats）：

| 日期 | 请求 | 缓存命中 | 平均输入 |
| --- | --- | --- | --- |
| 10-31 | 11 | 40.7% | 52,953 |
| 11-01 | 15 | 49.4% | 12,704 |
| 11-02 | 7 | 34.6% | 12,678 |
| 11-03 | 13 | 40.0% | 15,481 |

平均输入 5.3 万 → 1.2–1.5 万，约 **−75%**。

## 常见问题

**不配 embedding 能用吗？**
能，但只有标签联想，召回会明显变差。

**人格被改了怎么办？**
插件会改写人格里的 `【长期记忆】` 与 `【云上日记】` 两段，装之前先备份原人格。

**星图打不开？**
地址要带 `?token=`；本机 / 隧道访问在 2.1.0 起已免令牌。

**记忆太多会变慢吗？**
单会话 100–300 条最健康，超过 400 条建议 `/记忆 裁剪` + `/记忆 去重`。

**她说话怪 / 记错东西？**
先用 `/记忆 撤回 关键词` 作废错的记忆；措辞怪多半是记忆写法像说明书，
改写那条记忆比换模型有效。

**面板里点实验室 / 情绪？**
2.1.0 起会直接打开插件页面（8788），数据由插件提供，面板只做入口。
