## 它解决什么问题

普通聊天机器人「记不住」：上下文一过就忘，或者把几百条历史一股脑塞进 prompt 烧 token。

海浪把记忆拆成四层，各管各的寿命。更重要的是：

> **记忆不依赖上下文存活。** 它存在磁盘上，需要时被检索回来，重要的直接写进人格。

所以即使对话被截断、上下文被清空、甚至换一个模型，核心记忆仍然在。

## 四层记忆

| 层 | 内容 | 寿命 | 是否进人格 |
| --- | --- | --- | --- |
| **L1** | 最近 20 句原话（摘要 + 标签） | 滚动窗口 | 走上下文 |
| **L2** | 24 小时内的闲聊摘要 | 到期即删（热门续期） | 按话题注入 |
| **L3** | 偏好、约定、身份、习惯、边界 | 永久（除非被遗忘） | ✅ 写进人格 |
| **L4** | 每日原话存档 + 日记 | 永久 | 检索 / 翻档案 |

### L3 入库门槛

```
有长期信号词（喜欢/讨厌/习惯/约定/以后/每次/不要/名字/生日/边界…）→ 收
只有瞬时词（今天/刚才/现在/好累…）且无长期信号 → 拒
长度 < 8 或 > 160 → 拒
```

**例外**：你说「记住」而写入的事实（`pinned`）绕过所有门槛，且**永不下沉**。

## 情感系统

海浪记两路情绪，互不覆盖。

### 一、你的情绪（识别）

| 能力 | 说明 |
| --- | --- |
| 分句作用域 | `不是很难过，就是有点累` 两个分句分别判 |
| 否定与否定尾 | `不开心`、`开心不起来`、`喜欢不了` |
| 双重否定 | `不是不开心` → 正面 |
| 程度词 | `超级 / 特别 / 太 / 有点 / 稍微`，前后都吃 |
| 转折取后句 | `虽然烦，但是见到你就好了` → 后句为主 |
| 假设降权 | `要是 / 如果 / 的话` → ×0.75 |
| 反问降置信 | `难道…吗？` → ×0.6 |
| 转述降权 | `他说 / 她在 / 他们` → ×0.45，不算她的情绪 |
| 持续标记 | `最近 / 一直 / 老是` → 标记为持续情绪 |
| emoji / 表情码 | 😭😄 计入，`[em]e10317[/em]` 剥掉 |
| 中性词 | `还行 / 就那样` → 判中性，不触发安慰 |
| 强度分级 | `intensity` 0–1，强情绪单独触发安抚 |

### 二、她的情绪（自生成）

```
v_new = 惯性 × v_old + (1-惯性) × 基线 + 耦合 × 你的情绪 + 事件
arousal = 0.75 × 旧唤醒 + 0.25 × 你的强度 + 事件唤醒
```

| 成分 | 作用 |
| --- | --- |
| 惯性（默认 0.88） | 情绪不会一句就翻盘 |
| 基线（默认 0.08） | 长期回到微微偏正 |
| 耦合（默认 0.35） | 被你感染的程度 |
| 事件 | 被夸 +0.15、被凶 −0.25、被敷衍 −0.08、被依赖 +0.05、被逗笑 +0.08 |
| 创伤 | 被凶后 `trauma +2`，接下来几轮恢复更慢 |

**二维表达**：

| valence | arousal | 她会觉得 | 行为 |
| --- | --- | --- | --- |
| 正 | 高 | 挺来劲 | 话多一点 |
| 正 | 低 | 挺松快 | — |
| 负 | 高 | 有点烦躁 | — |
| 负 | 低 | 提不起劲 | 话少一点，别硬找话题 |
| 中性 | 高 | 有点躁 | — |

### 三、自我迭代

每轮回复后，比较「她实际说出口的情绪」与「她设定的情绪」：

| 差距 | 调整 |
| --- | --- |
| > 0.55 | 耦合 −0.02、惯性 +0.01（少被你带跑） |
| < 0.20 | 耦合 +0.01（更愿意共鸣） |
| 长期偏移 | 基线微调 ±0.004/次 |

参数存在 `state.self_mood_cfg`，`/情绪` 里能看到耦合 / 惯性 / 自适应次数。

### 四、交叉规则

你低落、她也低落时，注入「你自己也不在状态，别硬装开心去哄，说实话也行」——
防止假安慰。

## 联想与检索

### 候选来源（四条并行）

```
1.   标签命中    查询里出现词表标签
1.5  标签共现    命中标签的兄弟标签（共享 ≥2 条记忆）
1.6  语义标签    150 个标签也向量化，按余弦找最近标签
1.7  向量近邻    查询向量在全库找最近邻（阈值 0.55，按话题自适应）
2.   字面兜底    完全没候选时才启用
```

### 打分

```
score = Σ(1 + log(1 + 60/df)) × 1.4     标签 IDF
      + cos(query, mem) × 2.0            语义
      + jaccard(query, mem) × 1.2        字面
      + min(0.6, hits × 0.06)            被想起次数
      + max(0, 0.35 - 天数×0.01)         新鲜度
      + 0.9 × (1 - |情绪差|)             情绪共鸣
      + 0.35 / 0.25                      长期事实 / 日记加成
```

### 过滤

```
证据门槛：标签命中 或 余弦 ≥0.55 或 字面 ≥0.25
去重门槛：与已选记忆相似度 ≥0.72 丢弃
分数门槛：低于 score_floor 不注入（自适应 0.8–1.5）
字符预算：单次注入 ≤240 字（调优器可调 140–420）
噪音过滤：寒暄类摘要不注入
```

### 召回回退

一条都召不到时，门槛临时 ×0.72，并带上你**上一句话**再试一次。
只对 ≥6 字的句子生效——寒暄不放宽，避免硬塞旧事。

### 两跳扩展

从最强的 3 条往外走，每跳取关联更强、优先跨层的邻居，链上标注搭桥标签：

```
主人是大学生 → 希望称呼他为主人 ⟨称呼⟩ → 每次多写几句 ⟨边界⟩
```

桥标签条件：出现频率 ≤20%，且不属于元标签。

## 真实遗忘

每条事实带 `source`（owner / inferred）与 `confidence`，权重按可信度打折：
`conf < 0.5 → ×0.45`，`conf < 0.75 → ×0.7`。

```
稳定性 = 1 + 2 × 被想起次数
强度   = e^(-天数/稳定性) + 0.06 × min(5, hits)
权重   = 类型基础分 + 0.5 × (被想起次数 - 1) - 0.1 × 天数
```

| 触发 | 结果 |
| --- | --- |
| L2 强度 < 0.08 或超 24h | 删除，写 `forget_log.jsonl` |
| L2 被提起 ≥2 次 | 到期前续 48h，最长 3 天 |
| L2 被提起 ≥3 次且信息量够 | **晋升 L3** |
| L3 权重 < 1.0 或 180 天没提 | 标记 `parked`，写 `facts_archive.json` |
| 每天下沉上限 | 最多 3 条 |
| L3 下沉满 365 天 | 彻底删除 |
| L4 | 永不删除 |
| 事实带 `valid_until` | 到期移入归档 |
| 活跃事实 > `fact_capacity` | 按权重最低归档 |
| `confidence = 0` | 不再注入、退出人格 |

类型基础分：约定 / 承诺 / 身份 / 边界 **3.0** · 偏好 / 作息 / 习惯 **2.5** · 梗 / 表情 **1.6** · 其他 **1.3**。

## 日记

- 默认每 **14 天**一篇
- 格式：`日期 · 标题` → `【大纲】3–5 条` → `【正文】250–450 字`
- 人格里保留最新 1 篇正文，更早的只留大纲
- **满 24 篇自动合成年度合集**（原 24 篇删除）
- 启动时若已超阈值会自动补一次合并

## 记忆星图

插件启动后在 `web_port`（默认 **8788**）起一个带令牌保护的只读页面：

```
http://<服务器IP>:8788/?token=<state.json 里的 web_token>
```

### 星图页

- **环形分类**：按层级分圈（L1 / L3 / L2 / L4 / 日记），圈内按标签排序
- **球面散布**：自由探索，`⌗` 一键切换
- 拖动旋转（带惯性，松手会继续滑）、滚轮 / 按钮缩放（缓动）
- 搜索框按内容或标签过滤，未命中的点淡出
- 悬停显示气泡：内容 + 日期 + 标签
- 选中节点有呼吸脉冲环，悬停有柔光
- 时间过滤：1 小时 / 6 小时 / 24 小时 / 全部
- 底部「记忆脉络」：横轴是时间，每根竖线 = 一句话，光点 = 想起的记忆
- 导出 PNG、快捷键（空格 / `+` `-` / `F`）
- 自适应画质：帧率掉到 26 以下自动关辉光

### 情绪页

右上角「情绪」进入独立页面：

| 元素 | 含义 |
| --- | --- |
| 青色柱 | 她每天的情绪均值（向上偏轻、向下偏沉） |
| 紫色折线 | 你每天的情绪均值 |
| 底部细条 | 她今天逐小时的情绪 |
| 右侧卡片 | 我此刻 / 你这边 / 耦合 / 惯性 / 自适应次数 |

接口：`/api/mood?token=…`（结构见 `_web_mood`）。
页面支持 `?moodcheck=1` 自检。

## 省 Token 设计

| 机制 | 效果 |
| --- | --- |
| 短消息跳过检索 | 「嗯 / 好 / 在吗」不调 embedding、不注入 |
| 寒暄批次跳过模型 | 本地打标签，不调 LLM |
| 注入预算 | 240 字 / 4 条，调优器自适应 |
| 人格哈希 | 内容没变不重写人格，保护提示词前缀缓存 |
| 检索缓存 | 同一句 15 分钟内复用结果 |
| 输出清洗 | Markdown / 句尾句号 / 空行分段 |
| 群聊限流 | 超限直接不回，模型都不调 |
| 缓存自调优 | 读 `provider_stats`，每 10 轮爬山调参，退步回滚 |

**实测**（`provider_stats`）：

| 日期 | 请求 | 缓存命中 | 平均输入 |
| --- | --- | --- | --- |
| 10-31 | 11 | 40.7% | 52,953 |
| 11-01 | 15 | 49.4% | 12,704 |
| 11-02 | 7 | 34.6% | 12,678 |
| 11-03 | 13 | 40.0% | 15,481 |

平均输入从 5.3 万降到 1.2–1.5 万，约 **-75%**。

## 常见问题

**Q：不配 embedding 能用吗？**
能用，但只有标签联想，没有语义边和向量近邻，召回会明显变差。

**Q：人格被改了怎么办？**
插件会改写人格里的 `【长期记忆】` 与 `【云上日记】` 两段。安装前务必备份原人格。

**Q：星图打不开？**
地址要带 `?token=`，令牌写在 `state.json` 的 `web_token`，启动日志也会打印完整地址。

**Q：记忆太多会变慢吗？**
设计上单会话 100–300 条最健康。超过 400 条建议 `/记忆 裁剪` + `/记忆 去重`。

**Q：她说话怪 / 记错东西？**
先用 `/记忆 撤回 关键词` 作废错的记忆；如果是措辞问题，多半是记忆本身的写法（像说明书），改写那条记忆比换模型有效。

**Q：群聊里刷屏怎么办？**
默认每小时 6 条、间隔 8 秒，超了直接不回。也可以用「安静」口令。
